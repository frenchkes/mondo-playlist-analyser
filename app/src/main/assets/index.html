01 / Import your playlist

Paste a public Spotify playlist link (up to 100 tracks), then tap the TuneBad button below. MONDO will open TuneBad inside the app, run its playlist analysis, and bring the results back here. No Spotify login or paid API is needed.

CSV columns supported: title, artist, bpm, key (Camelot such as 8A), energy. You can also edit every value after import.

02 / Free BPM & Camelot analysis

MONDO uses TuneBad's free playlist analyser for BPM, musical key and Camelot. No paid API key or subscription.

MONDO hands your public playlist link to TuneBad, then imports its BPM, key and Camelot results back into this running order. TuneBad supports up to 100 tracks.

TuneBad measures BPM and musical key, not actual dancefloor energy. MONDO now creates a BPM-based starting estimate (1–10), then lets you adjust every track by ear. The estimate is a guide, not an audio measurement.

06 / Harmonic mixing reminder

Strong Camelot neighbours: same key (e.g. 8A → 8A), ±1 number in the same letter (8A → 9A), or relative major/minor (8A → 8B). Treat this as a guide — phrasing, basslines and ears still win.
